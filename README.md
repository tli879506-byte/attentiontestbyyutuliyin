👁️ 注意力测试 
“在这个时代，注意力仍然是一种慷慨，且比以往任何时候都更稀有、纯粹。”
一场披着“心理健康自测”外皮的互联网生态剥离实验，通过15 道题目，观测受试者的注意力离散程度。没有绝对的正解，只有你下意识的赛博生存策略。
本作品纯属虚构娱乐互动叙事，所有结果均属娱乐，不构成任何专业建议，不收集任何个人信息。
本作将结合 SVG 动画与前端特效，还原真实的心智过载，故含有微恐效果：包括但不限于弹窗、闪屏、变色、小动画以及部分可能引起强心理不适的网络生态与情感压迫写实内容；
光敏性癫痫患者及心脏病患者请谨慎参与测试。
本作包括4 个结局，系统会捕捉你选择“解决问题 (Method)”、“必出金句 (Bad)”或“倾听留白 (OK)”的倾向，以注意力集中于帖主真实意图为基准评分。

创作内核：
本作的核心理念脱胎于哲学家西蒙娜·薇依 (Simone Weil) 的著作《在期待之中》(Waiting for God)：
“诗人通过对实在之物的专注创造出美，同理可得爱的行为。得知此人饥渴交加，又同我一样存在着就足够了，其余的事情顺其自然。”
相比于急于给出建议或划清界限，本作试图探讨一种濒危的能力——在急于审判的世界里，仅仅是为了“确认对方的存在”而付出的注意力。
